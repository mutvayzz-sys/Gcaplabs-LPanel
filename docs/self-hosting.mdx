# Self-hosting the control panel

This repository contains local setup scripts and a Docker Compose stack. That source is not, by itself, a supported customer deployment guide for Headmaster.

A local stack does not establish that administrator sign-in, account identity, Cloud runtime provisioning, or inference routing are configured for a customer-managed environment. The older installation steps in this page described a different product and have been removed.
