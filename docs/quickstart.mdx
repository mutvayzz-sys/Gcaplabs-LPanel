# Quickstart

This guide covers the Headmaster entry points implemented by this control panel. It does not replace the Headmaster app's customer onboarding.

## For administrators

When the administrator integration is enabled, Headmaster can open the control panel using the signed-in account. The account must be explicitly linked to an existing panel administrator. A link does not grant an administrator role by itself.

If you do not see the control panel in Headmaster, ask your Headmaster administrator whether the integration is enabled and your administrator account is linked. See [Administrator access](/headmaster-integration) for the access and session rules.

## For Cloud runtime users

Model access is assigned per account. The Lite, Pro, and Max labels do not identify fixed provider models. The [Cloud model tier guide](/headmaster-cloud-inference) explains what the relay currently allows.
