# Headmaster licence panel

This repository implements the licence panel and Cloud control-plane services used by Headmaster. It connects administrator access with managed runtime identity, configuration synchronization, and account-based inference routing.

## What this repository provides

- An administrator workspace integrated with Headmaster sign-in when the integration is enabled.
- Identity-bound configuration for managed Cloud runtimes.
- Server-side model assignment and routing for the Lite, Pro, and Max tier labels.
- A repository-level implementation reference. It does not establish whether a feature is enabled in a particular deployment.

The Headmaster desktop app and account website are maintained separately. Read the [ecosystem map](https://github.com/mutvayzz-sys/gcaplabs-desktop/blob/main/ECOSYSTEM.md) for the five-repository overview.
